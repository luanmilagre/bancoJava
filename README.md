# 🏦 Banco Java

Projeto desenvolvido durante meus estudos de **Java**, com o objetivo de praticar lógica de programação e estruturas de controle através da criação de um sistema bancário simples via terminal.

## 📚 O que pratiquei

Neste projeto coloquei em prática:

* Variáveis e tipos de dados
* `if` e `else`
* Operador lógico `&&`
* `while`
* `do while`
* `switch`
* `break`
* `return`
* Operadores `+=` e `-=`
* Entrada de dados com `Scanner`
* Controle de tentativas de login
* Validação de informações
* Manipulação de saldo

## 🔐 Login

O sistema possui um login com:

* Número da conta
* Senha
* Limite de 3 tentativas

Após três tentativas incorretas, o acesso é bloqueado.

## 💰 Operações

Após o login, o usuário tem acesso a um menu com:

1. Saque
2. Depósito
3. Transferência
4. Sair

O sistema também realiza algumas validações, como verificar se existe saldo suficiente para realizar uma operação.

## 🎯 Objetivo do projeto

O principal objetivo não foi criar um sistema bancário real, mas **praticar os fundamentos de Java através de um projeto**, entendendo como diferentes estruturas podem trabalhar juntas.

Este projeto faz parte da minha evolução nos estudos de **Java e desenvolvimento backend**.

## 🛠️ Tecnologias

* Java
* Scanner
* Terminal/Console
